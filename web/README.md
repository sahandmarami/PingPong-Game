# 🏓 پینگ پنگ — نسخه وب

همان بازی در یک فایل HTML — بدون نصب، بدون اینترنت، مخصوص موبایل و دسکتاپ.

**بازی آنلاین:** https://sahandmarami.github.io/PingPong-Game/

## امکانات
- فیزیک واقعی ضربه: محل برخورد روی راکت جهت و قوس توپ را عوض می‌کند، سرعت حرکت راکت قدرت ضربه
- سرویس دو مرحله‌ای واقعی (جهش در زمین خودی، بعد زمین حریف)، قانون لتی، دیس و مچ‌پوینت
- ۴ سطح هوش مصنوعی با زمان واکنش، خطا و پیش‌بینی — هیچ سطحی شکست‌ناپذیر نیست
- ۱۲ کشور با پرچم (روی راکت‌ها هم می‌افتد)
- پیش‌نمایش زنده دو ربات در منوی اصلی (همان موتور بازی)
- صفحه رودررویی + شمارش معکوس ۳/۲/۱/شروع
- آمار محلی (بردها و بهترین نتیجه) + تنظیمات صدا و لرزش
- کاملاً فارسی و راست‌به‌چپ، فونت وزیرمتن داخل خود فایل
