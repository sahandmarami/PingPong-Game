## ✨ امکانات

- ⭐ **فیزیک واقعی (اولویت اصلی):** محل برخورد توپ روی راکت (چپ/راست) جهت برگشت را تعیین می‌کند، سرعت حرکت راکت هنگام ضربه قدرت و عمق ضربه را زیاد می‌کند، ارتفاع برخورد قوس پرواز را تغییر می‌دهد — توپ پرتابه‌ی واقعی با گرانش است (برخورد با تور، فرود روی زمین حریف، افزایش تدریجی سرعت در رالی‌های طولانی)
- 🤖 **ربات در ۳ سطح:** 🟢 آسان / 🟡 متوسط / 🔴 سخت (زمان واکنش، دقت، پیش‌بینی مسیر و احتمال خطا متفاوت — هیچ سطحی بی‌نقص نیست)
- 🌍 **۱۲ کشور با پرچم برداری:** ایران 🇮🇷 (پیش‌فرض)، چین، ژاپن، کره، آلمان، فرانسه، ایتالیا، اسپانیا، انگلستان، آمریکا، برزیل، ترکیه — فقط هویت و ظاهر، بدون توانایی ویژه (بازی منصفانه)
- 🎬 **پیش‌نمایش زنده در منو:** دو ربات با همان موتور بازی در پس‌زمینه‌ی منو مسابقه می‌دهند (کمی کندتر، بی‌صدا، بی‌پایان) با پوشش نیمه‌شفاف
- 🏆 **قوانین واقعی:** ۱۱ امتیاز با اختلاف ۲، سرویس هر ۲ امتیاز، اویت در ۱۰-۱۰
- 🎬 **جریان مسابقه:** پرچم‌ها («ایران در برابر چین») → شمارش معکوس ۳/۲/۱/شروع! → شمارنده‌ی رالی → صفحه‌ی نتیجه
- 🖐️ **کنترل لمسی روان** (رویدادمحور، بدون تأخیر) + پشتیبانی موس برای شبیه‌ساز
- 🔊 **صدا و لرزش** قابل خاموش/روشن + افکت‌های برخورد
- 💾 **آمار محلی:** بردها و بهترین نتیجه (فقط روی دستگاه)
- 🇮🇷 **فارسی کامل:** RTL، فونت وزیرمتن، اعداد فارسی

## 🛠 تکنولوژی

Kotlin 1.9 • Jetpack Compose (BOM 2024.06) • Canvas دستی • Gradle 8.7 + AGP 8.5.2 • minSdk 26 (اندروید ۸ به بالا)

## ▶️ اجرا و ساخت

### دانلود APK آماده
از صفحه‌ی [Releases](https://github.com/sahandmarami/PingPong-Game/releases) فایل `PingPong-v1.0-release.apk` را دانلود و روی گوشی نصب کنید.

### بازکردن در اندروید استودیو
1. `Open` → پوشه‌ی پروژه
2. Sync و سپس `Run` ▶️

### خط فرمان
```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # app/build/outputs/apk/release/app-release.apk
```
نسخه‌ی Release با keystore همراه پروژه (`app/keystore/pingpong.jks`، پسورد `pingpong123`) امضا می‌شود — برای انتشار رسمی، keystore خودتان را جایگزین کنید.
